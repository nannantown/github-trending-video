# 戦略 — AI Trend Daily（GitHub Trending Video）

## 売りたいもの

**現時点で直接売る商品はない。** 将来的に以下のいずれかへ導線を作る:

- a) 受託開発（AI / SNS自動化 / データパイプライン案件）
- b) 技術選定・導入コンサル
- c) 上記をパッケージ化した「販売コンサル」商品

方針は **フォロワー 1,000 到達までは無課金で育て**、到達後に商品化検討。

## 現状

- フォロワー: 20〜30（運用開始 2 週間）
- 1,000 再生を超えた動画あり → 情報の質を保てばスケール余地あり
- 2 週で 20〜30 は平均以上のペース

## ペルソナ（優先順）

### Primary: 技術投資判断をする立場のエンジニア / CTO
- 0→1 フェーズのスタートアップ、個人開発者、ソロCTO
- 「今どんな OSS が伸びているか」で技術選定する
- 受託・コンサルの発注元になりうる

### Secondary: 事業責任者 / PdM
- 技術の理解は浅いが、「何が来ているか」のキャッチアップには使う
- 動画で知識を得る → 自社で困った時に思い出される
- コンサル発注の発案者になりやすい

### Tertiary: 学習中のエンジニア
- フォロワー数は稼いでくれるが、直接の顧客にはなりにくい
- 無視はしないが、彼ら向けにチャンネルを歪めない

## コンテンツ柱（推奨比率）

| 柱 | 比率 | ねらい |
|---|---|---|
| ①GitHub Trending TOP5 解説 | 70% | 現状の軸、継続 |
| ②「この技術が実案件でこう使える」ビジネス視点 | 15% | Primary / Secondary 向けの差別化 |
| ③自分のプロジェクト事例 / デモ | 10% | 「この人は手を動かす人」という信頼シグナル |
| ④業界の読み解き | 5% | 月1 程度、長期フォロワー育成 |

### 具体ネタ例
- ②: 「この OSS、スタートアップで使うなら月額○円削れる」「この AI ライブラリ、受託で組むならこう見積もる」
- ③: 「SNS 自動投稿を作った話（sns-hub そのもの）」「Claude Routine で毎日記事を書かせる」
- ④: 「2026 Q2、AI OSS のトレンドを振り返る」

## NG パターン

| NG | 理由 |
|---|---|
| 入門者向け深すぎる技術解説 | Primary/Secondary 層が離脱 |
| 煽り系サムネ（「〇〇は終わった」等） | 一瞬伸びるがブランド毀損 |
| 特定技術スタックの宗教論争 | 案件獲得で不利になる |
| 雑な情報転載（README 読み上げレベル） | 差別化ゼロ、選ばれない |

## 商品化ステップ

```
Phase 1 (〜2026-10 目安): フォロワー 1,000 到達
  - コンテンツ柱を維持しつつ、視聴者層をエンジニア側に寄せる
  - プロフィール bio で「技術選定の相談OK」だけ軽く出す

Phase 2 (フォロワー 1,000 到達後):
  - LP / 無料相談フォーム動線をプロフィールに追加
  - 月1 で「案件やりました」系の動画を差し込む
  - DM / 問い合わせ件数を計測

Phase 3 (フォロワー 3,000 + 問い合わせ 月5件 到達後):
  - 受託パッケージ商品化（SNS自動化テンプレート、AI導入支援パック等）
  - 技術ブログ化も検討
```

## ファネル（Phase 2 以降）

```
SNS 視聴（GitHub Trending 解説）
  ↓ 信頼形成（複数本視聴）
プロフィール bio（「技術選定の相談可 / 受託案件対応」）
  ↓
LP or 無料相談フォーム
  ↓
DM / メール問い合わせ
  ↓
商談 → 受託 or コンサル
```

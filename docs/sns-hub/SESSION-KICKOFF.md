# 新セッション用キックオフプロンプト

新しい Claude Code セッションを `~/projects/sns-hub/` で開いたあと、最初に以下を送るとコンテキストが一気に乗ります。

---

**コピペ用プロンプト**:

```
このセッションでは ~/projects/sns-hub 配下にある 2 つの SNS 動画自動投稿プロジェクトを横断的に管理します。
まず CLAUDE.md と docs/shared-patterns.md を読んで、両プロジェクトの現状・セットアップ・共通ハマりポイントを把握してください。
その後、各リポジトリ (github-trending-video, coffee-daily-video) のディレクトリ構造と GitHub Actions の最新 run 状況をざっと確認し、今朝の自動投稿が両方とも成功したかどうかを教えてください。
```

---

## なぜこのキックオフでいいか

- 親 CLAUDE.md が両プロジェクトの全体像と ID 辞書を提供
- shared-patterns.md が過去の障害パターンを提供
- `gh run list` で現状の稼働を確認すると、次の作業の出発点が明確になる

## ユーザーが追加で伝えると良いこと

- 「これから〇〇プロジェクトに新機能を追加したい」など、当日の目的
- 最近変えた設定や、気になっている挙動
